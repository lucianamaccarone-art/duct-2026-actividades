# Analizador de Frecuencias de Palabras

Este script lee un archivo de texto (`texto_integradora.txt`), cuenta la frecuencia de aparicion de cada palabra usando un diccionario y genera un grafico de barras con las 10 palabras mas frecuentes (`grafico_frecuencias.png`).

## Requisitos
El proyecto requiere Python 3 y las siguientes bibliotecas:
- `matplotlib`
- `pytest`

Se pueden instalar ejecutando: `pip install -r requirements.txt`

## Ejecucion
- **Analizar y generar grafico:** `python analizador.py`
- **Correr pruebas unitarias:** `pytest`
